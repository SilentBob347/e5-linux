# 2026-10-26 更新说明

适用：E5、T551M、M8、T512N、远航 41S、守护宝 K1；新增岭燕 LYM-10K 安装包。

- 优化双卡联网初始化：主卡拨号不再等待副卡可选的身份信息，联网后再补全。保留原有基带上电、AT 回放与射频初始化顺序。
- 所有机型的自动网络模式默认改为 152；仍可手动选择 134，已保存的明确选择不会被升级覆盖。
- 新增 LYM-10K 适配：独立触摸驱动、屏幕、基带运行环境、声音及充电配置，并接入公共看板、CPU 调频调压、温控与 USB 角色控制。
- LYM-10K 可手动使用“主机＋外部供电（实验）”，与普通 OTG、自动角色模式分开控制。
- 安装器、系统更新和 Diff Studio 补齐 LYM-10K 型号识别；继续提供 Windows、Apple Silicon 与 Python 入口。

验证说明：E5 的新拨号服务已实机热部署并验证双卡识别及联网。LYM-10K 完成固件对照、编译及离线回归，尚未在该机实测，不代表触摸、充电、通话等所有硬件已经验收。本次没有宣称彻底解决群友偶发“无模组”，也没有加入固定时间重拨。

完整包包含 Diff Studio 和系统补丁插件。保留 TF、userdata 镜像及独立内置分区安装方式；FM_U20、U30 Pro 不属于本次发布范围。
