# E5 系列更新说明（2026-10-24～25）

适用 E5、T551M、M8、T512N、远航 41S、K1。安装器单独修订会保留原固件版本，ZIP 名中的 `installer-g…` 表示安装工具修订。

- **基带 NV 管理完善**：网页新增“基带NV设置”，可对比原机与 OpenWrt 工作 NV、查看遮挡后的 IMEI、手动备份及下载，并明确选择同步方向。覆盖操作需输入 `yes` 确认。
- **升级保留校准数据**：更新、重装保留工作 NV 和来源记录；备份不可用时，先验证本机原始 NV，再由用户决定是否恢复，避免不知情地丢掉工作修改。
- **修复更新失败**：修复早期开机保留 NV 时随机源不可用的问题；运行时更新载荷、NV 暂存改放持久存储，减少 RAM 占用，修正离线内存预算重复计算。
- **修复安装残留锁**：退出后自动释放安装锁，旧版失效空锁自动回收；实际仍在写入的任务继续受保护。锁工具独立随包，保留原载荷身份，方便继续已有安装任务。
- **Diff Studio 随包提供**：Windows、Apple Silicon 和 Python 入口直接放在完整包中，共用已有后端。支持自动保存、导入和导出版本摘要，减少反复读取旧完整包的需要。
- **完善屏幕与后台状态**：补齐 K1、远航 41S 的默认配置及亮屏、通话状态、SIM 属性和短信相关处理；看板读取恢复后及时清除旧错误，减少切卡后显示上一张卡的数据。
- **保留用户省电选择**：增加支持机型的 CPU0 休眠控制与持久化，完善常驻服务行为。
- **安装器体验**：改善 Mac 解压目录识别，明确更新兼容范围，移除 E5 安装时多余的 BL 解锁状态阻断。

此范围汇总近期已提交功能，并非每次安装器修订都重新修改系统镜像。
