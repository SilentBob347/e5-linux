# 2026-10-27 更新说明

- **E5 屏幕色阶**：补齐 ST7365P 控制器的色彩抖动配置，同时覆盖开机接管 bootloader 已点亮画面和正常面板初始化，设置后回读，改善暗色渐变断层。其他机型不套用该控制器设置。

- **自动网络模式**：全部机型默认 152，保留 134 兼容选择和用户已保存设置。
- **LYM-10K**：新增独立触摸、屏幕、基带环境、声音及充电配置，接入公共看板、CPU 调频调压、温控和 USB 角色控制；支持手动“主机＋外部供电（实验）”。
